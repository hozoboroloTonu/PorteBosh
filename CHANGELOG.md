# Changelog

All notable technical changes to the PorteBosh project are documented in this file.

## [1.0.0] - 2026-10-22
### Production Release
- Complete offline student academic workspace for Android.
- SQLite/Drift architecture with reactive UI streams.
- Saturday-first routine management with time conflict detection.
- Course workspaces with document viewers and auto-saving notes.
- Offline backup archive export and validated restore.
- Developed by Mahmud Tonmoy.
